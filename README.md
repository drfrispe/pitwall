# Pitwall

Pitwall is a small Windows app that helps a gaming PC run well: it checks settings that cost frames, explains each one in plain words, and only changes something when you click. It never touches a game while it runs, never reads game memory and works alongside anti-cheat.

## Download

Get `Pitwall.exe` from the [latest release](../../releases/latest) and run it. It needs Windows 10 or 11 and no admin rights to start.

Windows may show **Windows protected your PC** the first time, because the exe isn't code-signed. Click **More info**, then **Run anyway**. Updates that Pitwall installs itself don't show this.

## Updates

Pitwall checks this page once a day, downloads a new version in the background and only accepts files signed by the publisher's key. Updates never install while a game is running.

## Privacy

No accounts and no telemetry. Nothing about your PC leaves it. The update check fetches one small file from this page.

This repository holds releases only, not source code.
